# Фаза 5 — Поток записи эмоции (согласованный спек)

> Статус: **спроектировано, код НЕ начат**. Колесо (Фаза 4) готово.
> Это продолжение после выбора эмоции на колесе (`/record`, фича `emotion-wheel`),
> сразу после подтверждения «Это оно».

## Шаги потока

1. **Интенсивность.** 5 растущих светящихся «огоньков» цвета выбранной эмоции — от едва
   тлеющего к яркому. Тап выбирает уровень 1–5. Без цифр/процентов/баров. Под выбранным —
   короткая поэтичная подпись. Огонёк может пульсировать в ритме 5-5.
2. **Причина.** Внешнее событие / внутреннее состояние (2 варианта → `cause_type`).
3. **Локализация в теле.**
   - Силуэт человека: **белый, слегка размытый контур, пустой внутри. БЕЗ чакр.**
   - Тап выбирает анатомическую зону. Зоны: ладонь, предплечье, плечо, грудь, шея, голова,
     живот, таз, бедро, колено, голень, стопа.
   - Для конечностей важна **сторона (левая/правая)**: рука = ладонь/предплечье/плечо;
     нога = бедро/колено/голень/стопа. Центральные зоны (грудь, шея, голова, живот, таз) —
     без стороны.
   - Можно выбрать **несколько** зон.
   - Маркер на выбранной зоне зависит от **валентности эмоции** (см. ниже):
     позитивная → маленький **светлячок** (тёплое свечение);
     негативная → **чёрная колючка**.
4. **Дыхание.** Практика 5-5.
5. **Сохранение** → таблица `emotion_entries`.

> Поле «Осознание» (свободная заметка) в MVP-потоке **не делаем** — отложено вместе с
> crisis-фильтром (см. CLAUDE.md §15). Вернётся в фазе crisis-safety.

## Валентность эмоций (для маркера светлячок / колючка)

- **Позитивные** (светлячок): радость, любовь, покой, интерес, **удивление**.
- **Негативные** (колючка): страх, печаль, стыд и вина, отвращение, гнев.

(Удивление отнесено к позитивным по решению Артёма.)

## Данные / БД

Таблица `public.emotion_entries` — **ещё НЕ создана**. Черновик полей:

| поле | тип | примечание |
|---|---|---|
| `id` | uuid pk | |
| `user_id` | uuid | FK `auth.users` on delete cascade |
| `family_id` | text | id семьи из каталога в коде |
| `shade_id` | text | id оттенка |
| `emotion_name` | text | снимок имени на момент записи |
| `emotion_color` | text | снимок цвета |
| `intensity` | smallint | check 1..5 |
| `cause_type` | text | check ('external','internal'), nullable |
| `body_zones` | text[] | id зон вида `hand_left`, `chest`, `knee_right` |
| `created_at` | timestamptz | default now() |

RLS: own CRUD (select/insert/update/delete по `user_id`). Индекс `(user_id, created_at desc)`.

> ⚠️ Локализация = **анатомические зоны** (`body_zones`), НЕ чакры. Чакры остаются только в
> онбординге и будущем «световом теле».
>
> Поля `awareness` пока нет — добавим миграцией, когда вернётся «Осознание» + crisis-фильтр.
