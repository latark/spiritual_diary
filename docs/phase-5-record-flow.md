# Фаза 5 — Поток записи эмоции (согласованный спек)

> Статус: **спроектировано, код НЕ начат** (по просьбе остановиться). Колесо (Фаза 4) готово.
> Это продолжение после выбора эмоции на колесе (`/record`, фича `emotion-wheel`),
> сразу после подтверждения «Это оно».

## Шаги потока

1. **Интенсивность.** 5 растущих светящихся «огоньков» цвета выбранной эмоции — от едва
   тлеющего к яркому. Тап выбирает уровень 1–5. Без цифр/процентов/баров. Под выбранным —
   короткая поэтичная подпись. Огонёк может пульсировать в ритме 5-5.
2. **Причина.** Внешнее событие / внутреннее состояние (2 варианта → `cause_type`).
3. **Локализация в теле.**
   - Силуэт человека: **белый, слегка размытый контур, пустой внутри. БЕЗ чакр.**
   - Тап выбирает анатомическую зону. Зоны: ладонь, предплечье, плечо, грудь, шея, голова,
     живот, таз, бедро, колено, голень, стопа.
   - Для конечностей важна **сторона (левая/правая)**: рука = ладонь/предплечье/плечо;
     нога = бедро/колено/голень/стопа. Центральные зоны (грудь, шея, голова, живот, таз) —
     без стороны.
   - Можно выбрать **несколько** зон.
   - Маркер на выбранной зоне зависит от **валентности эмоции**:
     позитивная → маленький **светлячок** (тёплое свечение);
     негативная → **чёрная колючка**.
4. **Дыхание.** Практика 5-5.
5. **«Осознание».** Свободная заметка (см. открытый вопрос №1).
6. **Сохранение** → таблица `emotion_entries`.

Таблица `public.emotion_entries` — **ещё НЕ создана**. Черновик полей:

| поле | тип | примечание |

> ⚠️ Локализация = **анатомические зоны** (`body_zones`), НЕ чакры. Ранее ошибочно
> закладывался `body_chakras` — отменено. Чакры остаются только в онбординге и будущем
> «световом теле».

## Открытые вопросы (на следующую сессию)

1. **«Осознание» (свободный текст) + crisis-фильтр.** По CLAUDE.md §6 любой свободный ввод
   обязан проходить детектор крайних состояний (нельзя ослаблять даже для тестов). Не выбран
   вариант: (а) поле + базовый keyword-фильтр сейчас, LLM-слой и алерты куратору позже;
   (б) поле сейчас, crisis целиком — отдельной фазой до беты; (в) пока без свободного текста.
2. **Валентность эмоций для маркера** (светлячок/колючка). Предлагается:
   позитив = радость, любовь, покой, интерес; негатив = страх, печаль, стыд, отвращение, гнев.
   **Удивление** — нейтральное: решить (нейтральный маркер? по силе/оттенку?).
