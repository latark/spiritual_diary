# Дизайн-система «Духовного дневника»

Продукт медленный, тёмный, ритуальный. В MVP только тёмная тема. Перед новым UI
посмотри ближайший существующий компонент (`BottomNav`, `BreathingExercise`,
`LightBody`, `.btn-gold` в `globals.css`) и повтори его язык. Токены лежат в
`src/shared/styles/globals.css` (`@theme`), они доступны как Tailwind-утилиты.

## Шесть железных принципов

1. **Темнота — норма.** Фон `bg-canvas` (#0F0B1F), это «вход в практику». Не светлые экраны.
2. **Минимум текста.** Иконка или анимация вместо подписи. Текст пиши через скилл `spiritual-voice`.
3. **Свечение вместо рамок.** Состояния (hover/focus/selected) задавай через glow/ring, не borders.
4. **Округлено всё.** Радиус ≥12px; на крупных блоках 20–32px.
5. **Анимации медленные.** 300–500ms норма. Никаких резких 100ms и bounce (кроме флипа карты).
6. **Никаких прогресс-баров с %, бейджей «achievement unlocked», счётчиков очков.** Только
   метафоры свечения, дыхания, тотема, растущего тела света.

## Токены (используй как Tailwind-утилиты, не хардкодь hex)

**Поверхности/текст:** `bg-canvas` · `bg-surface` · `bg-surface-raised` · `text-ink`
(основной) · `text-ink-muted` (вторичный) · `border-line` (тонкие разделители, нужны редко,
вместо них свечение).
**Акценты:** `text-gold`/`bg-gold` (#D4AF37, primary) · `gold-soft` · `violet` (secondary).
**Вибрационная шкала** (кольца/индикаторы): `vibe-low` → `vibe-mid` → `vibe-high` →
`vibe-transcendent` (тёмно-красный → серо-фиолетовый → золотой → тёплое свечение).
**Мягкая семантика:** `danger` (#C97A7A, тёплый красный, не технический).
**Радиусы:** `rounded-sm`(12) `rounded-md`(16) `rounded-lg`(20) `rounded-xl`(24)
`rounded-2xl`(32). Произвольные — `rounded-[2rem]`.
**Свечение:** `shadow-glow` · `shadow-glow-soft` · `shadow-glow-violet`.
**Шрифты:** `font-display` (Cormorant, заголовки/акценты) · `font-sans` (Inter, UI).
Прозрачность токенов — слешем: `bg-canvas/80`, `ring-gold/40`, `text-ink-muted/50`.

## Свечение вместо рамок — как на практике

- **Hover/selected:** свечение нарастает. Не двигай элемент и не давай border. `hover:shadow-glow`,
  кольцо `ring-1 ring-gold/40 hover:ring-gold/70` (см. кнопку фазы в `LightBody`).
- **Focus:** мягкое золотое свечение вместо синего UA-ring. Глобально уже задано
  (`:focus-visible { box-shadow: var(--shadow-glow-soft) }`). Для SVG/кастома —
  `focus-visible:` с `drop-shadow`, `outline: none` плюс `-webkit-tap-highlight-color: transparent`.
- **Поверхности поверх фона:** полупрозрачность и `backdrop-blur` (`bg-canvas/80 backdrop-blur-md`)
  вместо сплошной заливки с рамкой.
- Условные классы — через `cn()` (`@/shared/lib/cn`).

## Анимации

- **Тайминги 300–500ms**, `ease` мягкий (`--ease-gentle`). Резкое и elastic нельзя,
  кроме намеренного флипа карты дня (`--ease-out-back`, ~800ms).
- **Появление контента** — `animate-fade-up` (fade плюс slide-up 8px, 250ms), без резкости.
- **Готовые именованные анимации** (в `@theme`): `animate-breathe` (ambient-пульс 5-5,
  10s, главная кнопка и «дышащие» элементы) · `animate-glow` (пульс золотого свечения 5s,
  CTA) · `animate-fade-up` · `animate-aura-pulse` · `animate-light-float` (парение тела света).
  Бери их вместо новых @keyframes, если подходит.
- **Framer Motion** (motion v12+) — для сложного: drill-down, шаги, частицы. Дефолты те же
  (300–500ms, gentle). Переходы между шагами — slide, появление — fade плюс slide-up.
- **Reduced motion обязателен.** Уважай `prefers-reduced-motion: reduce` (как
  `BreathingExercise`): отключай частицы и тяжёлое движение, смысловую суть оставляй.

## Два «дыхания» — не путать

- **Ambient-пульс 5-5** (`animate-breathe`, 10s): главная кнопка и «живые» элементы тихо
  дышат вдох-выдох по 5 сек.
- **Дыхательная практика** (`BreathingExercise`) — это box-breathing 4-4-4-4 (вдох,
  задержка, выдох, задержка), 4 цикла. Не «5-5». Если трогаешь практику — это 4-4-4-4.

## Primary CTA

Главная кнопка действия — класс `.btn-gold` (стеклянное золото, свечение разгорается на
hover) плюс утилита высоты/ширины в разметке (`btn-gold h-12`). Геометрию задаёт разметка,
вид — класс. Не пересобирай золотую кнопку заново.

## Запрещено (железно) и чем заменить

| Нельзя | Чем заменить |
|---|---|
| Прогресс-бар с % | метафора: точки-огоньки, нарастающее свечение, фазы тела света |
| Бейдж «achievement unlocked», очки, баллы, стрик-счётчик | рост/яркость тела света, тихая смена фазы |
| Стандартный spinner | мягкий пульс свечения плюс тёплый текст («…настраиваем канал») |
| Жёсткая рамка для состояния | `shadow-glow` / `ring-gold` |
| Синий focus-ring (UA) | золотое `focus-visible` свечение |
| Светлая тема / белый фон | `bg-canvas`, тёмная тема |
| Резкая анимация <200ms, bounce | 300–500ms, `ease-gentle` |
| Хардкод hex в классах | токены (`text-gold`, `bg-surface`) |

**Допустимые индикаторы прогресса** (принцип №6 не нарушают, это метафоры, а не
метрики): ряд точек-циклов (как в `BreathingExercise`), «фаза N из M» тела света, степпер
онбординга свечением. Запрещены именно проценты, очки и бейджи-достижения.

## Прочее

- **Mobile-first** (база ~380px), тёмная тема. На мобайле нижний таб-бар с золотой
  пульсирующей «Записать», на десктопе сайдбар. Респонсив через `md:` и т.п.
- **Иконки** — Lucide (`strokeWidth` 1.5–1.75, тонкие), размер через `size-*`.
- **next/font** для шрифтов (уже подключены), `next/image` где уместно. Исключение — когда
  нужен `mix-blend-mode`, там сырой `<img>` с eslint-disable, как в `LightBody`.

## Самопроверка

- Тёмный фон, токены вместо хардкода hex?
- Состояния — свечением/ring, не рамками; focus золотой, не синий?
- Радиусы ≥12; крупные блоки скруглены сильнее?
- Анимации 300–500ms, gentle; reduced-motion учтён?
- Нет прогресс-баров с %, бейджей, очков, стандартных спиннеров?
- Primary-действие — `.btn-gold`, не самодельная кнопка?
- Тексты — через `spiritual-voice`?
