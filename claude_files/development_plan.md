## 0. Ключевые решения, зафиксированные на старте

| Решение | Значение |
|---|---|
| Формат | Веб-сайт (Next.js), responsive, mobile-first |
| Бэкенд | Supabase (managed, EU-регион) |
| Платежи | ЮKassa |
| ИИ | Откладывается на самый конец. Сначала MVP без ИИ |
| Голосовой ввод | Откладывается вместе с ИИ (зависит от Whisper) |
| Астрология | Откладывается на пост-MVP |
| Серверы ПДн | ⚠️ 152-ФЗ — открытый юридический риск, нужен ответ юриста |
| Биометрический lock | Не делаем, magic link достаточно |
| Удаление отдельных записей | Не делаем — только архивирование. Принцип «записи навсегда» |
| Терминология | Используем: чакры, вибрации, Высшее Я, жизненная сила. Не используем: МидгасКаус, Эслер, эслеровцы, лярвы, Абсолют |
| Возраст | Только 18+ в MVP, детская версия — потенциально пост-MVP |
| Позиционирование/брендинг | Решаем позже, ближе к запуску |

### Что в MVP есть

Авторизация, личный кабинет, онбординг с **диагностикой профиля чакр**, колесо эмоций с привязкой к чакрам, **полная запись эмоции по структурированному шаблону (включая поле «Осознание» с возможностью дополнения)**, **отдельная практика работы с 50 парами установок ума с 21-дневными циклами аффирмации**, календарь, прогресс / световое тело / жизненная сила, стрики, контент дня (статичные эмоция дня и карта дня из 50 пар установок), уведомления, оплата, crisis safety на keyword-фильтре, админка.

### Что НЕ в MVP (см. Раздел «Отложенные задачи»)

ИИ-анализ еженедельный, ревизия паттернов через ИИ, голосовой ввод, астрология, ревизия по 7 сферам как фича, инстинкты как сущность, биометрический lock, детская версия, сезонные разблокировки, лунно-астрологический контекст, Telegram-бот.

## 20. Принципы сквозной работы

1. **Безопасность.** RLS на каждую новую таблицу, никаких `service_role` ключей в браузере, prepared statements, валидация входов через Zod
2. **Тёмная тема** как единственная в MVP. Светлая — пост-MVP
3. **Без ИИ-плейсхолдеров.** Все «послания тотема» в MVP — статичные шаблоны
4. **Анимации.** 300–500ms норма, Framer Motion с пресетами, общие easing в design tokens
5. **Мобайл-фёрст.** Каждая фича проверяется на 380px, потом адаптируется на десктоп
6. **«Записи навсегда».** Удаление отдельных записей не предлагается в основном flow
7. **Контент.** Тексты по чакрам, блокам, установкам и связанным практикам — из методички и статей школы. Кастомного копирайта существенно меньше, чем планировалось в v1.0

## 21. Открытые вопросы перед стартом разработки

1. **152-ФЗ.** Юрист подтверждает риск-аппетит школы на хранение в EU?
2. **Контент.** Кто пишет: опросник диагностики чакр (21 вопрос), описания 24-32 эмоций, тексты тотемов, тексты эмоций дня (30-66 шт.) — это **существенно меньше** чем в v1.0, потому что 50 установок ума и тексты по чакрам/блокам уже есть в методичке.
